### 3. Опис архітектури проєкту

Опишіть основні класи вашого проєкту, їхню взаємодію та загальну логіку програми. Можна додати UML-діаграму класів.

#### Клас `Visitor` (Абстрактний базовий клас)
- **Призначення:** `Слугує основою для всіх відвідувачів таверни, реалізує загальні атрибути та інкапсуляцію даних за допомогою @property.`
- **Атрибути:** `_name (ім'я), _race (раса), _gold (кількість золота).`
- **Методи:** `spend_gold(), interact() [абстрактний], __str__(), __repr__().`

#### Клас `Customer` (Підклас 1)
- **Наслідує:** `Visitor`
- **Призначення:** `Описує звичайного відвідувача таверни різних рас, який робить замовлення улюблених напоїв.`
- **Додаткові атрибути/методи:** `_favorite_drink (улюблений напій), перевизначений метод interact().`

#### Клас `Adventurer` (Підклас 2)
- **Наслідує:** `Visitor`
- **Призначення:** `Описує героя-шукача пригод із визначеним класом та рангом, який взаємодіє з дошкою квестів.`
- **Додаткові атрибути/методи:** `_hero_class (клас героя), _rank (бойовий ранг), перевизначений метод interact().`

#### Клас `Troublemaker` (Підклас 3)
- **Наслідує:** `Visitor`
- **Призначення:** `Описує проблемного відвідувача (дебошира), який створює конфлікти та має рівень агресії.`
- **Додаткові атрибути/методи:** `_aggression_level (рівень агресії), calm_down() (зниження агресії), перевизначений метод interact().`

#### Клас `Tavern` (Клас-менеджер)
- **Призначення:** `Керує колекцією відвідувачів, елементами меню, запасами таверни, організацією подій і вирішенням конфліктів.`
- **Основні методи:** `add_visitor(), remove_visitor(), prepare_item(), serve_visitor(), organize_event(), manage_inventory(), resolve_conflict(), search_visitors(), filter_by_type(), sort_visitors_by_gold().`

### 5. Висновки
Опишіть, чого ви навчилися під час виконання цієї лабораторної роботи. Які принципи ООП були застосовані? З якими труднощами ви зіткнулися при командній роботі через Git та як їх вирішували?

Під час виконання лабораторної роботи ми засвоїли принципи об'єктно-орієнтованого програмування: абстракцію, наслідування, інкапсуляцію (захист даних через @property) та поліморфізм при обробці різних типів відвідувачів таверни.
